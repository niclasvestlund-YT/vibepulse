opens its page at boot. Existing six/eight-switch Labs choices are preserved.
A saved OFF overrides the install seed after restart. The OpenRouter page and
poller are absent when it is off. API credentials remain in the Mac Keychain;
the panel receives only summaries from a separate local service.

then RESTART NOW after changing its selection. Horizontal swipes navigate
between enabled VibePulse pages; the OpenPulse bottom indicator switches
between spend and allowance/account details.
