VibePulse v1.5.0 brings the desk display to e-paper. **Paper USB edition** uses
a light background, large quota numbers and a physical switch to keep your
Claude Code and Codex activity within easy reach.

## VibePulse, on paper

<p align="center"><img src="https://raw.githubusercontent.com/niclasvestlund-YT/vibepulse/v1.5.0/docs/img/epaper397/glass-quota.jpg" width="640" alt="Owner photograph of VibePulse Paper on the real Waveshare 3.97-inch e-paper display, showing a historical Codex reading"></p>

A real **Waveshare ESP32-S3-ePaper-3.97-Kit, SKU 33811**, connected over USB to
a Mac. This owner photograph shows the earlier `paper-0.1.1` pilot and a
historical 14% reading; it is not a claim about today's quota. The current
`paper-0.2.0` firmware and source-rendered layout are included in this release.

The dedicated 800 × 480 monochrome target lives in VibePulse alongside the
AMOLED profiles. It reads the existing local VibePulse service, with no
separate Usage Pulse plugin, provider API keys or new cloud account.

## Four pages, one physical switch

Turn the three-way switch to browse **Codex**, **Claude**, **Projects** and
**Device**. Press it to return to Codex. Provider pages show weekly quota,
remaining percentage, reset time and available agent activity. Projects brings
Codex and Claude activity together.

<p align="center"><img src="https://raw.githubusercontent.com/niclasvestlund-YT/vibepulse/v1.5.0/docs/img/epaper397/codex.png" width="800" height="480" alt="Native 800 by 480 Paper 0.2 Codex layout with synthetic 38 percent quota and two active agents"></p>

This native one-bit fixture uses **synthetic data**, reproduced from the same
renderer as the USB host. Missing readings show a dash; old readings are
marked stale. Switching to Claude is built in, but real Claude values require
a working local Claude source. Grok and OpenRouter are not connected in the
Paper edition; their existing previews on other profiles keep their own setup
and verification limits.

## Calmer updates

The host checks for data every 30 seconds and redraws only when visible
content changes. Observation timestamps alone send a USB heartbeat. Changed
pages and values use partial refresh; startup and the refresh after ten partial
updates use a full cleanup refresh, which can visibly flash.

The owner confirmed correct orientation, live Codex readings, navigation and
quieter page changes on one Mac-connected unit. Extended ghosting, long soak,
Windows/Linux physical operation, battery/charging, audio, Wi-Fi/OTA and remote
answers remain unqualified. E-paper can retain an old picture without power;
a visible number alone does not prove the host is live.

## Documentation and tooling

The README now starts with board choice and the core desk-display experience,
with the Paper guide, real hardware photos and native fixtures easy to find.
The bundled IBM Plex fonts include their open font license and provenance.
Development tooling also moves to pinned **Pillow 13.0.0** for its security update.

The release adds dedicated firmware CI, portable reader tests, source/schema
checks, a first-poll clock regression, content-based refresh tests and native
publication-raster comparisons. Hardware evidence remains separate from CI.

## Install or upgrade

This is a **source release**. Paper uses its own firmware target and USB reader;
it is not an AMOLED OTA update. No personalized firmware image or full-device
backup is attached. Identify the exact board, preserve a private verified
backup and follow the guide before any installation.
